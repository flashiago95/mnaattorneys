### Notes
- All images are referenced by **filename only** - just overwrite the file in `assets/images/`, no code changes needed.
- If a file is missing, the page now shows a plain grey block (no "image not found" text), so the layout stays clean while you're sourcing photography.
- `.webp` files can be replaced with `.jpg` or `.png` - just keep the same filename and extension, or update the `src=` path in `index.html` / `about.html` if you change the extension.
